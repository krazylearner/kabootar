# Operator-final disputes

**Status:** accepted

Exactly one system operator principal exists, with no user-facing roles and no appeal
path; the operator reviews evidence and issues a final verdict of release, refund, or
split. This matches the source's "administration decision is final" rule and avoids a
moderation hierarchy or jury system.

**Consequences:** users have no recourse against a bad ruling; the operator is a single
point of failure and a single point of trust; the only protection is the append-only
operator audit log.
